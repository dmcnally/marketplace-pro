## Design and implementation boundary

Each takeaway is one bucket: content ownership, membership authorization, its allergen list and its single currency apply throughout. There is no multi-site hierarchy.

Product and variant content and menu content retain immutable recordable versions. Product publication publishes a consistent product-and-variants version; menu publication snapshots presentation and structure. Live per-variant availability remains separate. Product-level availability and allergen controls are bulk UI, not additional stored product states or inheritance. Every domain mutation must emit events, including each affected record in bulk operations. Archives retain snapshots/history; live filtering does not rewrite published versions. Menu replacement and live-menu archiving/unpublishing must be atomic, including concurrent requests. These are design contracts, not runtime verification.

## Verification

Mapped all 114 source bullets below to current editable screen content. Read back text, fonts, layer types and parent bounds across all 73 screens. Desktop frames are 1440px and mobile frames 390px wide. All inspected text uses Inter. The UI is editable text, frames, vectors and component instances, with no flattened UI images.

Visually reviewed representative staff availability, product desktop/mobile editing, categories, allergen warnings, menu editing, desktop/mobile preview, product publication, archive restoration, Revert all, before/after comparisons and mobile navigation. Fixed inherited button wrapping, mobile canvas color, image hierarchy and affected content reflow; repaired frames passed targeted bounds checks and visual review.

Navigation and principal review/history/archive entry points link to Figma design frames. This is a screen/state design, not a fully simulated application. The menu preview shows editable sample artwork separately for draft menu/section images and published product imagery; no production photography was supplied.

Orders retains staff/editor destinations with an explicit deferred-work label. No order processing, checkout, advanced collaboration, automatic merging, timed availability or arbitrary historical restoration is introduced.
